# MINDAY — трекер привычек

Минималистичный habit tracker со стеклянным интерфейсом (Next.js App Router, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Recharts, Lucide).

## Запуск

Нужен Node.js 18.18+ (лучше 20 или 22).

```bash
npm install
npm run dev        # http://localhost:3000
```

Сборка и запуск в продакшн-режиме:

```bash
npm run build
npm start
```

> Совет: если папка лежит в OneDrive, синхронизация `node_modules` может замедлять установку. При желании перенесите проект в папку вне OneDrive.

## Взаимодействие

- **Ctrl/⌘ + K** — командная палитра: переходы, отметка привычек, тема, таймер, итоги недели, экспорт. Если ввести название, которого нет среди команд, палитра предложит создать такую привычку.
- **Быстрое добавление** — строка на главной: название + Enter.
- **Плавающая кнопка (+)** — новая привычка, таймер, напоминание, итоги недели, команды. На телефоне это центральная кнопка нижней панели.
- **Свайпы на телефоне** — карточка вправо = выполнить, влево = пропустить.
- **Порядок привычек** — «Привычки → Порядок»: перетаскивание за ручку, кнопки ↑↓ или стрелки клавиатуры.
- **Итоги недели** — цифры, лучшие и проблемные привычки, оценка и короткая рефлексия (сохраняются по неделям).
- **Таймер** — для любой привычки, продолжает идти при закрытом окне, по окончании предлагает отметить привычку.
- **Звук и вибрация** — в настройках; звук по умолчанию выключен. Вибрация работает там, где браузер её поддерживает (Android); Safari на iPhone её не поддерживает.

Анимации построены на единой системе (`src/lib/motion.ts`): общие длительности, кривые и пружины, только transform/opacity, с учётом `prefers-reduced-motion`.

### Данные и правила
- Каждая отметка — отдельная запись `{ habitId, date, status, count, completedAt }`, ключ «привычка + дата» исключает дубликаты.
- Пропуск не сохраняется заранее: он вычисляется только для прошедших дней (или при явной отметке «Пропустить»). Будущие дни никогда не считаются пропущенными.
- Расписание версионируется: изменение действует с сегодняшнего дня, прошлое не пересчитывается. Переименование и прочие правки историю не трогают.
- Пауза и архив не превращают дни в пропуски; при возврате из архива период превращается в паузу.
- Удаление привычки удаляет и её историю (без «осиротевших» записей), есть отмена через уведомление и альтернатива «В архив».
- «Каждый день» и «дни недели» — серия в днях; «N раз в неделю» — серия в неделях.
- Учитываются выбранный часовой пояс и час начала нового дня (для «сов»).
- Демо-данные хранятся отдельно от реальных и удаляются при выходе из демо.

### Подключение сервера в будущем
- `lib/storage/adapter.ts` — интерфейс `StorageAdapter` (асинхронный). Достаточно реализовать его поверх API/БД с авторизацией.
- `lib/reminders/notifications.ts` — интерфейс `NotificationChannel`. Для уведомлений при закрытом браузере добавьте реализацию на Service Worker + Web Push и серверную рассылку.

## Ограничения первой версии
- Данные хранятся в браузере (localStorage) на одном устройстве — используйте экспорт JSON для резервной копии.
- Напоминания приходят, пока вкладка с приложением открыта (в том числе в фоне). При закрытом браузере уведомлений нет.
